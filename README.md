# MateMate

Мой координатор агентской разработки: **WezTerm → Herdr → MateMate в Pi → исполнители**.

В этом репозитории лежит весь код координатора: инструкции, расширения Pi,
навыки, скрипты, документация, тесты и настройки установки. Клонировать FirstMate
отдельно больше не нужно. Код развивается в `Ryukkw/MateMate`.

## Запуск

Открой WezTerm — он автоматически подключится к Herdr. Из любого терминала:

```sh
matemate
```

Если в Herdr уже есть нужный агент, продолжай его беседу. Для первого запуска
координатора открой оболочку внутри Herdr и выполни:

```sh
cd ~/MateMate
pi
```

Подтверди доверие папке, введи `/login` и авторизуйся у провайдера модели.
Если клонировал в другую папку, используй её путь. Чтобы продолжить последнюю
сессию Pi в этой папке, выполни `pi -c`.

Первое сообщение:

> Выполни стартовую проверку MateMate. Используй Herdr и исполнителей Pi.
> Общайся по-русски. Запускай не больше двух исполнителей одновременно.
> Перед установками и изменением настроек спрашивай меня.

Первый проект:

> Добавь https://github.com/OWNER/REPO в режиме local-only. Пока ничего не меняй.
> Изучи приложение и объясни, как его запустить. Ничего не отправляй на GitHub
> и не объединяй без моего разрешения.

`Ctrl-b`, затем `q` отсоединяет Herdr, сохраняя процессы. Закрытие WezTerm
не останавливает сервер Herdr. После перезагрузки компьютера процессы нужно
запустить снова; история агента продолжается отдельно.

## Картинки и восстановление диалогов

MateMate остаётся консолью: картинки вставляются вложениями или локальными путями и отображаются в чате метками, без отдельного приложения и окон предпросмотра.
На Mac штатная вставка картинки в Codex работает через `Ctrl+V`; дополнительный плагин MateMate использует `Ctrl+Alt+V`, оставляя штатные клавиши без изменений.
Настройка консоли устанавливает интеграции Herdr для Pi и Codex, чтобы после перезапуска восстанавливались привязанные диалоги.
Первый запуск Codex после установки интеграции может запросить проверку нового хука Herdr; без доверия этому хуку автоматическое восстановление сессии не заработает.
Настройка Windows Terminal описана в [установщике для Windows](setup/bin/clipboard-windows.ps1).
Если старая вкладка открылась как shell, прежний диалог можно выбрать через `codex resume --all`; пустая вкладка сама по себе не означает удаление истории Codex.

## Установка на другом компьютере

Нужны macOS или Linux, Git, GitHub CLI, jq, curl, Node.js LTS и npm. WezTerm
устанавливается отдельно. Добавь `~/.local/bin` в PATH своей оболочки:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Клонируй приватный репозиторий после входа в GitHub:

```sh
gh auth login
gh repo clone Ryukkw/MateMate
cd MateMate
bash setup/bin/install.sh
matemate
```

Установка использует код координатора из этого клона. Pi и AXI устанавливаются
в версиях из `setup/config/npm-packages.txt`; Herdr, Treehouse и No Mistakes —
через официальные установщики текущих релизов. Это не автономный офлайн-архив
всех сторонних инструментов. Установка требует сети, меняет npm prefix на
`~/.local`, ставит интеграцию Pi и AXI-хуки поддерживаемых агентов; установщик
No Mistakes запускает его daemon. Глобальные npm-пакеты ставятся без sudo.

На другом компьютере нужно отдельно войти в провайдера Pi. Токены, переписки,
проекты и работающие процессы через Git не переносятся.

## Структура — одна рабочая папка

```text
MateMate/
├── AGENTS.md           инструкции координатора MateMate
├── .pi/                расширения Pi
├── .agents/skills/     навыки координатора
├── bin/                скрипты управления агентами
├── docs/               документация
├── skills/             дополнительные навыки
├── tests/              тесты унаследованного движка
├── setup/
│   ├── bin/            установка, применение, проверка, запуск
│   └── config/         переносимые шаблоны настроек терминалов и инструментов
├── config/             локальная конфигурация; создаётся установкой, вне Git
├── data/               локальные данные; создаются при работе, вне Git
├── state/              состояние агентов; создаётся при работе, вне Git
└── projects/           проекты; добавляются отдельно, вне Git
```

`~/.local/bin/matemate` ссылается на `setup/bin/matemate` в этом клоне.
Настройки и сессии самих Pi, Codex и Herdr по-прежнему хранятся в стандартных
каталогах этих приложений в домашней папке.

## Настройки и проверка

Измени шаблоны в `setup/config/`, затем:

```sh
bash setup/bin/apply.sh
bash setup/bin/verify.sh
```

Перед заменой отличающихся настроек создаются резервные копии. `apply.sh`
настраивает WezTerm, подключает исправление цветов в `.zshrc` или `.bashrc`,
выбирает Herdr + Pi и регистрирует команду запуска. Стороннюю команду с тем же
именем он не перезаписывает. Применение шаблонов заменяет локальные backend и
crew-harness; остальные локальные настройки сохраняются.

WezTerm: непрозрачность 50%, размытие 24, контрастная ANSI-палитра. Новые окна,
вкладки и панели WezTerm по умолчанию подключают MateMate; рабочие вкладки
создавай внутри Herdr. Обычная оболочка: `wezterm start -- /bin/zsh -l`.
Профиль обычного macOS Terminal: `setup/config/MateMate.terminal`; импортируется
двойным кликом и выбирается вручную в настройках Terminal.

Если уже работающий Codex унаследовал `NO_COLOR=1`, после завершения его работы
выйди через `/exit` и в той же панели выполни:

```sh
unset NO_COLOR
export COLORTERM=truecolor
codex resume --last
```

## Переход с прежней установки

Рабочий корень теперь — этот клон MateMate. Старая папка `~/kun-agent-workspace`
перенесена в `~/Backups/MateMate/kun-agent-workspace-<дата>` и больше не
выбирается установщиком или командой запуска. Открытые Herdr-панели сохраняют свой прежний текущий каталог: для новой
координаторской сессии перейди в `~/MateMate` вручную. Процессы старых панелей
автоматически не перезапускаются. При переносе в старой папке были только
локальные `config/backend` и `config/crew-harness`; они скопированы сюда.

## Обновление

```sh
git pull --ff-only
bash setup/bin/verify.sh
```

Обновления кода приходят из **Ryukkw/MateMate**. Версии внешних инструментов
обновляй отдельно. Внутренние имена `fm-*` и некоторые команды со словом
Firstmate сохранены для совместимости скриптов; пользователю координатор
представляется как MateMate.
