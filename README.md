# MateMate

Мой сетап агентской разработки: **WezTerm → Herdr → Pi / FirstMate → исполнители в Git worktree**.

MateMate — название этой конфигурации и команда запуска. Координатор основан на
[FirstMate](https://github.com/kunchenguid/firstmate) Kun Chen. Его код и рабочее
состояние хранятся отдельно; этот репозиторий содержит настройки и установку.

## Запуск на этом Mac

```sh
matemate
```

Команда открывает или присоединяет Herdr. Если внутри уже работает Pi — продолжай
беседу. Если видна только оболочка, выполни `pi` для первой сессии или `pi -c`
для продолжения последней.

При первом запуске Pi подтверди доверие рабочей папке, затем введи `/login` и
авторизуйся у провайдера. Учётные данные не переносятся этим репозиторием.

Первая команда агенту:

> Выполни стартовую проверку FirstMate. Используй Herdr и исполнителей Pi.
> Общайся по-русски. Запускай не больше двух исполнителей одновременно.
> Перед установками и изменением настроек спрашивай меня.

Первый проект:

> Добавь https://github.com/OWNER/REPO в режиме local-only. Пока ничего не меняй.
> Изучи приложение и объясни, как его запустить. Ничего не отправляй на GitHub
> и не объединяй без моего разрешения.

Эти предпочтения передаются агенту сообщением; это не технический лимит числа агентов.

`Ctrl-b`, затем `q` отсоединяет Herdr. Процессы продолжают работать.

## Что сохранено

- `config/wezterm.lua`: непрозрачность 50%, размытие 24, шрифт 14, клавиши с `Ctrl-a`.
- Контрастная ANSI-палитра: красный, зелёный, жёлтый, синий, фиолетовый и бирюзовый.
- `config/terminal-colors.sh`: снимает унаследованный `NO_COLOR` только в
  интерактивных оболочках WezTerm / Herdr и задаёт `COLORTERM=truecolor`.
- `config/firstmate/`: Herdr как backend, Pi как harness исполнителей.
- `config/npm-packages.txt`: точные версии Pi и AXI при подготовке сетапа.
- `config/firstmate-revision`: проверенный коммит FirstMate для новой установки.
- `bin/`: установка, применение настроек, проверка и запуск.

Проверено при создании: Pi 0.85.1, Herdr 0.9.0 (протокол 22),
Treehouse 2.3.0, No Mistakes 1.70.1. Бинарные установщики загружают актуальные
релизы, поэтому весь сетап не является побитово воспроизводимым.

## Установка на другой машине

macOS или Linux. Установи Git, GitHub CLI, jq, curl, Node.js LTS и npm;
WezTerm устанавливается отдельно. На Linux параметры macOS в конфиге WezTerm
не дают macOS-размытие.

Добавь в `~/.zshrc` или `~/.bashrc`:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Из клона этого репозитория:

```sh
bash bin/install.sh
gh auth login
bash bin/verify.sh
matemate
```

Первый `install.sh` может завершиться на проверке GitHub, если вход ещё не выполнен.
После входа достаточно повторить `verify.sh`.

Установка записывает npm prefix `~/.local`, устанавливает пакеты и официальные
бинарники, настраивает Pi-интеграцию Herdr и AXI-хуки для поддерживаемых агентов,
включая настройки Claude Code, Codex и OpenCode. Установщик No Mistakes запускает
его daemon. Скрипты требуют доступа к сети, глобальные npm-пакеты ставятся без sudo.

Существующий `~/kun-agent-workspace` используется автоматически. На новой машине
FirstMate создаётся в `~/.local/share/matemate/firstmate` на зафиксированном коммите
(detached HEAD). Путь можно выбрать через `MATEMATE_HOME`; при нестандартном пути
задай эту переменную и при установке, и при дальнейших запусках.

## Изменение настроек

Редактируй файлы `config/`, затем:

```sh
bash bin/apply.sh
```

Перед заменой отличающихся настроек создаются резервные копии рядом с оригиналом.
`apply.sh` также подключает `terminal-colors.sh` из `~/.zshrc` (или `~/.bashrc`
для Bash). Уже работающие приложения сохраняют старое окружение до перезапуска.
WezTerm автоматически перечитывает свой конфиг. После изменения интеграции
перезапусти Pi. Перемещение клона MateMate требует перенастройки ссылки
`~/.local/bin/matemate`.

Авторизация, переписки, проекты, состояние Herdr и FirstMate находятся вне этого
репозитория. Их не нужно добавлять в Git. Создание этого локального репозитория
само по себе ничего не публикует на GitHub.

### Если Codex стал одноцветным

В оболочке перед запуском проверь `printenv NO_COLOR`. Значение `1` отключает
подсветку. Заверши Codex, когда он не занят, и в той же панели выполни:

```sh
unset NO_COLOR
export COLORTERM=truecolor
codex resume --last
```

Новые интерактивные оболочки уже получают исправление автоматически. Не нужно
останавливать сервер Herdr. Терминал отображает цвета, которые выдаёт приложение;
он не добавляет синтаксическую подсветку произвольному обычному тексту сам.

## Обновления

Обновляй компоненты по одному и запускай `bin/verify.sh`. Для существующей
установки FirstMate на `main` подходит `git pull --ff-only` из его рабочей папки.
Свежая установка закреплена на коммите: переход на другую версию делай явно,
с проверкой состояния Git; после проверки обнови `config/firstmate-revision`.
Версии npm меняй в `config/npm-packages.txt`. Повторный `install.sh` ставит
записанные версии npm и актуальные бинарники, но не обновляет существующий FirstMate.
